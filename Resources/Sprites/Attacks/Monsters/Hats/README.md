# Hats

These four hats are small easter eggs in the barrage rounds. Their designs are
pretty clearly inspired by characters from **Touhou Project**. They're fan-made
designs, not official Touhou Project game assets or an official collaboration
or anything. Just a little easter egg, yep.

| File              | Source size | Design reference |

| `hat-suwako.png`  |       64×64 | Suwako Moriya    |
| `hat-yukari.png`  |       64×64 | Yukari Yakumo    |
